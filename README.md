# Dice Game — Prism Labs

On-chain dice rolling game. Stake ETH, roll, win/lose based on RNG.

## Mechanics

- **Stake**: Send ETH to the contract
- **Roll**: Request a random number (Chainlink VRF or block-based)
- **Outcome**: Win multiplier or lose stake
- **Track**: Games played, total volume, win rate

## Deployment

- **Testnet**: Base/Sepolia (zero cost iteration)
- **Mainnet**: After validation
